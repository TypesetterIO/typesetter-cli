# Welcome

This book was created by `typesetter init`. Replace the files in `content/` with your own writing, then run `typesetter generate` again.

## Chapters

Every Markdown file in `content/` is a chapter. Chapters are added in file name order, so start each file name with a number: `01-welcome.md`, `02-formatting.md`.

The table of contents lists the first and second level headings of each chapter. Change that with `toc-levels` in `config.php`.

## The cover

The cover of this book was generated from the `title` and `author` in `config.php`. To use your own, add a `cover.jpg` or a `cover.html` to `my-theme/`.
